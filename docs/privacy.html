Privacy

{{GAME_NAME}} collects nothing about you. It has no accounts, no analytics and no advertising.

What stays on your computer

Saves, settings, screenshots and optional local logs are written to the game's data folder on your computer. They never leave it unless you choose to attach them to a bug report yourself.

Update check

When the update check is on, the game downloads a small public file from GitHub to see whether a newer version exists. GitHub sees that request like any web request (see GitHub's privacy statement). You can turn the check off in the settings.

Bug reports

The in-game bug report opens a pre-filled GitHub issue in your browser. Nothing is sent until you submit it there; you see everything it contains first.
